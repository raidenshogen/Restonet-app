Récupération de mot de passe

Si vous avez perdu votre mot de passe mais que vous connaissez votre identifiant, saisissez votre identifiant dans le champ ci-dessous. Votre email doit avoir été renseigné dans RestoNet.

Si ce n'est pas le cas, ou que vous avez changé d'adresse mail, saisissez votre email dans le champ ci-dessous.

Dans les deux cas, vous allez recevoir rapidement par mail un nouveau mot de passe pour accéder à RestoNet. Utilisez ce nouveau mot de passe pour accéder au site.

Attention, pensez à vérifier que le mail n'a pas été déplacé dans le dossier "courriers indésirables", "spam" ou encore dans la "corbeille".
